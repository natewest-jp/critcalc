## gcsim

<https://github.com/genshinsim/gcsim>

- **`src/lib/utils/gauge.ts`** mirrors gcsim's reactable logic and its per-frame `Tick()`: gauge decay, the reaction priority order, and the aura bookkeeping. It was written in August 2026 against gcsim's MIT-licensed releases (v2.47.2 and earlier), so the MIT notice below applies to the ported logic.
- **Frame data** (frame counts, hit marks, tick cadences and ICD groups in the character data) is factual measurement taken from gcsim's source and from running it. It is credited here, but no gcsim code is copied into the data.
- **`scripts/gcsim-dump/`** links a current gcsim checkout as a Go library. gcsim has been licensed AGPL-3.0-or-later since 2026-09-19, so the dumper is a combined work with AGPL code. critcalc's own code is AGPL-3.0 (see [`LICENSE`](LICENSE)), so the combination is covered with no further terms. The dumper is a development tool: it is never part of the site's build output.

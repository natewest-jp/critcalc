# Visualizers overhaul, round 4: saved per profile (2026-11-02)

**Status:** ✅ merged to `main` 2026-11-02 (`feat/viz-saved`, merged in order with the overhaul's other rounds; pushed 2026-11-04). Nate: "All of these changes are solid"; refinement continues in a fresh session. Real Safari checked by Nate on 2026-11-04; the phone pass is on the to-do.

## 1. Why

Round 3 folded set-once settings into summary lines, which only pays off if they stay set. Every
instrument forgot everything on a reload (`+page.svelte`: "nothing internal is persisted"), so
a player's pity, Radiance counter, goal and build were gone each visit.

## 2. What changed

- **`ProfileRecord.instruments`** (optional; no database version bump): each instrument's
  share state, by id. Absent means never moved. The instrument sanitizes it when applied, as it
  does a link.
- **The session** (`saveInstrument`, `instrumentState`) writes it like the roster: debounced
  (`SAVE_DELAY_MS`), instrument by instrument onto the stored record, so two tabs saving
  different instruments keep both. It flushes wherever the roster does (a profile switch, a
  hidden tab, a backup, a restore, a retry) and is frozen with it.
- **The backup** carries it with its profile (object states only).
- **The page** applies a profile's saved state after each handle binds (the defaults snapshot
  comes first, so Defaults still knows the defaults), saves from then on, and on a profile
  switch shows the new profile's state, or the defaults if it has none. A link opened on a cold
  load wins over the saved state and is then kept, as a link opened later already was. Defaults'
  Undo checks the profile is still the one it was pressed in.

## 3. Found on the way: round 1's backup

Round 1 moved the stored workspace to v2, but the backup's `sanitizeVizWorkspace` took only v1,
so a restore would have dropped the layout. Fixed on round 1's branch (`fix(visualizers): a
backup keeps the v2 workspace`, with a failing test first), and the stack rebased onto it.

## 4. Not done

- **No journal.** The documents and the roster go into the unload journal; instrument states
  don't. A hard reload inside the 400ms delay can lose a slider's last step. A hidden tab
  flushes first, which covers an ordinary reload (checked).
- What a share state leaves out is not remembered: Wish odds' import report, the Gauge's pin,
  the Crit heatmap's roll. The values they set are.

**The frame grammar (say it in one sentence): time axis on top, the rotation renders in the middle, you write to it from the bottom.**

- **Composer** (`.rp-composer`, bottom edge INSIDE the frame): single-line CodeMirror box, left edge aligned to the portrait column's right edge (`margin-left: LABEL_W` inline), darker well (`color-mix(in srgb, #000 40%, --rp-chart-bg)`), **1px three-state border — resting `--rp-line`, hover dire@50% (`color-mix(in srgb, var(--dire-tint) 50%, transparent)` — FULL-strength dire was vetoed as too loud), focused back to `--rp-line`** (caret = the active signal; no focus ring). Pencil glyph retired — the well+border ARE the textfield signal. KQM + PNG sit side-by-side just outside the box's right ("send/submit" position), `.rp-composer-btn` chips (24px, min-width 84px so "✓ Copied" doesn't reflow), on-button transient feedback (1.6s label flip), PNG menu opens UPWARD. Nate's insight: the box+side-buttons read as a CHAT INPUT, so it belongs at the bottom like every chat app; this also ended a full bottom-ruler exploration — ruler went back to TOP (DAW convention) same session.
- **Ruler** on top: labels above stubs, seam below, gridlines drop from seam. **View cluster** (`.rp-view-cluster`) rides its right end: `TOTAL 21.4s` chip (uppercase micro-key + value, chip backing) · zoom · NOTES (badge + panel toggle; panel unchanged at timeline right). Fade = fixed 40px ramp to `--rp-chart-bg` with contents padded past it (percentage ramps let ticks bleed through translucent chips).
- **Lane borders are top-only** (`.rp-nb-lane`/`.rp-moonsign-lane` border-top; `.rp-team-buffs` none — its opening line is char4's border-bottom; label cells mirror via `rp-label-cell--lane`/`--lane-sep`): whichever lane is bottom-most ends clean. Export hlines: a lane's closing line draws only when another lane follows.
- **Tab strip = document chrome only**: tabs, Reset, Save, Load, Share. Principle that drove the whole redistribution: **every control lives on the thing it acts on** (KQM = the notation text; PNG = the chart; Notes = the roster's caveats; Share/Save = the document).
- **Warning colors unified into dire** (round 1): unknown tokens = dire wavy underline + dire text; the amber "Unrecognized:" chip row DELETED (squiggle is the only surface); `~?s` = dimmed time-green non-italic (honest gap, not error). `--skill-tint: #f7cb56` / `--burst-tint: #ec6761` now live at `:root` (app.css) for cross-tool reuse (Team Builder provenance / crit-viz ICD are candidate consumers); the editor consumes them.

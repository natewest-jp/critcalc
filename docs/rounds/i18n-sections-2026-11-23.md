# The full-screen sections — 2026-11-23

Round 5 of the translation item in `docs/todo.md`, after notices, the shortcuts sheet, and
page meta (`i18n-notices-keys-seo-2026-11-23.md`): Library, Profile, Teams, and Trash,
extracted and drafted in Japanese, still hidden. Stacked branches: `feat/i18n-sections`
(extraction), `feat/i18n-ja-sections` (the Japanese draft and two fixes), and this record
on `docs/i18n-sections`. Roster waits for the Builder: its strings share the Builder's
ledger surface (`tb`).

## What was built

- **201 messages extracted, English unchanged.** These sections render on the client, so
  the prerender diff (which also matched) can't see them. The check was each one walked in
  headless Chrome on `main`'s build and this one, in Theorycraft and in a new profile with
  a team's details open: 824 lines of text and labels, with no difference.
- **Plurals and counts:** "N days ago", "N days left", "N teams", and "+N more teams" are
  plural messages. The profile delete dialog's counts reuse Settings' count messages, and the
  list joining them is a message, so the commas are the locale's.
- **Module-level tables** read their messages at each use: the lineup presets (getters, so
  `TEAM_PRESETS`, a filter of them, keeps working) and the profile color names (`labels()`).
- **Dates and months** follow the page's language: Theater lineup names (`lineupLabel` used
  en-US) and the cycle cards' date ranges. The Abyss card's half tags (1st, 2nd) were too
  short for the extractor to list; they are messages now.
- **A profile made with an empty name** is named in the page's language, the same words as the
  form's placeholder. The migrated profile keeps its stored English name.
- **The team name field sizes by columns** (`src/lib/i18n/columns.ts`, tested): its `size`
  counts Latin characters, so 新しいチーム showed as 新しいチ…. Latin text sizes as before.

## Reverted: placeholders stay English

"Lineup 1" (made a message last round), "Tab 1", and "Imported team" are placeholders that
`isMintedLabel` (`migrate.ts`) knows by their English, and a placeholder is never saved as a
name. A translated one would no longer match, and would be saved as if the player had typed
it. All three stay English, with a comment at each site and on `isMintedLabel`.

## Left in English on purpose

The Moonsign and Hexerei bonus names (game terms, marked as a genshin-db data gap), notation
(C6, R1, the A and B pair tags), and the built-in profile's name, Theorycraft. Character,
weapon, and artifact names are game data, waiting on genshin-db's lookups.

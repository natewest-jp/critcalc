**The insight (Nate, 2026-07-23):** `isCurated` (characterLint) is a PURE frame-data gate (frames on normal.hits[0] + skill), fully orthogonal to `deriveCapabilities` (reads only Effects/AbilityTags, authored in Stages 1-3 from web research — NOT from genshin-db directly). So the 6 uncurated chars (illuga, kachina, lohen, prune, sandrone, zibai — `blank` is a 7th zero-cap sentinel) have COMPLETE, derivable, targeted, con-gated capabilities; only frame TIMING is missing. What's unauthored in the stubs is exactly the frame-gated on-field DMG — the RP-relevant piece, not the TB-relevant one.

**Decision — split the trust signal by tool:**

- **Team Builder** should filter uncurated chars normally, gating on `caps.length > 0` (uses existing `entry.caps`, NO new field — Nate rejected a stored `capsCurated`). This is a PROXY swap: everywhere TB keys off `curated` as "capability data trustworthy" → move to caps-presence. Sites: `facets.ts:splitRoster` (the `!entry.curated` bucketing), `atlas.ts` (`e.curated &&` provider gate, ×2), `team.ts` (`anyUncurated`→coverage `unknown`), `DetailCard.svelte` (banner text currently says "capability data below is incomplete" — WRONG under new stance, must reword + add a frame-specific chip, NOT a generic "uncurated" chip that would undermine trust). `blank` stays excluded via existing `+page.svelte` `c.id !== 'blank'`.
- **Rotation Planner** owns the honesty burden: it currently fakes timing for frameless chars via generic fallback with NO warning (violates "never fake timing"). Needs an in-bar "approximate timing — not frame-curated" label. Label, don't block (Nate).

**Persistence is forward-safe:** saved rotations (`SavedNotation.notation`) and shared links (`encodeRotation`→`?r=`) store NOTATION TEXT, re-parsed on load. When frames land, old rotations/links AUTO-UPGRADE — no migration. Stubs already carry real cooldowns (sidecar-verified), so only per-action animation length refines, not cooldown gating or notation validity.

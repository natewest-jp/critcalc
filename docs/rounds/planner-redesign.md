## Nate-approved decisions (2026-07-11 kickoff)

- **Composition:** timeline becomes THE chart — `.vz-anim-frame` on `#081225`, floating on Dire black; the old blue card + browser-tab chrome dissolves. Tab bar + Save/Load/Share become a restyled strip. Four character panels flex wider layouts on wide screens **if easy**.
- **Density:** license to breathe — larger type (rem), taller lanes OK; only constraint is pixel-accurate timeline alignment.
- **`--el-*` colors LOCKED** (recently tuned). **Three-phase bar system NOT sacred** — greenlit to replace if a better idea emerges during redesign.
- **Hollow elements:** discouraged broadly, not banned. OK for selected-state text buttons (see `.vz-chip.active`). For overlapping bars needing transparency, borders are acceptable — most palatable when border ≈ fill but slightly more distinct (like `.vz-panel`'s top hairline).
- **Controls:** ping slider → settings overlay (gives stubbed settings panel first real content); zoom inline with ruler (Option A / DAW convention); freed controls row = total rotation duration + unknown-token warnings + NOTES toggle.
- **NOTES button:** add a tiny `!` notification circle top-right when caveats exist for loaded characters — circle `--dire-tint`, exclamation `--text`.
- **NB + Moonsign lanes:** flat placeholder colors for now — Nate has specific color concepts for a follow-up round; do NOT invest in their coloring during the initial redesign.
- **SVG overlay:** stick with the decided hybrid renderer (2026-05-07) — one `xForTime(t)`, connectors + gridlines in a single `<svg>`; DOM keeps text-bearing/hoverable elements. PNG export later = separate data→SVG render.
- **Sequencing:** Fable's call. Proposed: design comps → chrome/frame/typography → lane-by-lane solid-shape pass → SVG overlay + controls → cN panel rows → sample rotations content last.
- **Carry-throughs (non-negotiable):** SSR hydration-safety pattern (`docs/rounds/rotation-planner-ssr-fix.md`), lazy CodeMirror import, scroll-latch + pointer-guard machinery (Safari lessons — don't rewrite).

# Parser and timeline bug sweep (2026-07-05)

> Moved from Claude's working memory on 2026-10-29. A dated record: it describes things as they were when written, so check the code and `.claude/rules/` before relying on it.

**STATUS: COMPLETE — everything below is fixed and MERGED to `main` (fast-forward to `fc3802a`, pushed 2026-07-06). This doc is retained as the record of what was found/fixed and the verification method.**

Multi-agent audit (6 auditors × 3 adversarial verifiers per finding; 2-of-3 vote to confirm) of `notationParser.ts`, `tokenizer.ts`, `RotationTimeline.svelte`, run 2026-07-05 on `main` at `fbea140` (363/363 tests green — all of these are latent, unpinned by the suite). 20 raw findings → 19 confirmed → **14 unique bugs** after dedup (Kazuha found 4×, E-handler order 2×, stance extensions 2×). 1 finding refuted (parser variant selection ignoring `AbilityVariant.conditions` — 1/3 votes).

Line numbers valid at `fbea140`. Most repros were verified by actually running vitest against the real modules.

## HIGH

1. **Kazuha C1 cdReset resets EVERY character's E queue** — `notationParser.ts:2405`. `for (const queue of eChargeQueues.values()) queue[0] = localCursor` has no caster filter; map is rotation-global, keyed by char-prefixed ability id. Fix: filter keys by caster's ability ids. Secondary defect in same loop: unconditional `queue[0] = localCursor` can push an ALREADY-READY charge later. Repro: `Cyno E > Kazuha E Q > Cyno E` @ Kazuha C1 → second Cyno E at 3.75s instead of 7.5s. Found independently by 4 auditors, 12/12 votes.
2. **Unbounded bracket repeat count → freeze/OOM** — `notationParser.ts:785` (regex at 771). `999999999[N1C]` typed in the editor synchronously expands inside the per-keystroke `$derived.by`. N-counts cap at N9; bracket counts have no cap. Fix: clamp count.
3. **Tokenizer name-absorb loop swallows concatenated runs** — `tokenizer.ts:234`. Absorb loop stops only on anchored whole-word matches, so `Bennett QEN1N2~2s` (the module header's own documented example, lines 31-37) becomes one character token → whole segment silently dropped. Fix: also terminate on words starting with `ACTION_FIRST_CHARS` (what `splitConcatenated` would split). Note: `formatNotation.ts` (`formatKQMPaste`) would split these but is dead code, imported nowhere.
4. **Bracket inner concatenated content expands to zero** — `notationParser.ts:784`. `tokenizeNotation('_ ' + inner).slice(1)` hits bug #3, so `9[N2C]` expands to NOTHING, silently. Same root cause as #3 — fixing #3 should fix this; add a regression test for both.
5. **E handler evaluates states/drain/variant BEFORE the charge-cooldown wait** — `notationParser.ts:2530` (evals at 2492-2513, wait at 2530). Q handler does it in the right order (2308-2316). Two verified symptoms: (a) wait crossing a stance end casts the stale in-stance variant with wrong CD queue (`Cyno Q E E ~13s E E`); (b) drain decay over the wait is skipped → phantom stacks (Skirk `E E` shows SS 86.5 instead of 45). One fix: reorder like the Q handler.
6. **Timeline crash on stale persisted artifactSetId** — `RotationTimeline.svelte:1193`. `artifactSet!.shortName` after a null-tolerant `?.` at 1178; `loadLoadout` (stores.ts:138-151) does no id validation, so a stale/hand-edited localStorage id throws TypeError inside the `teamBuffRows` derived → planner dead on every reload until localStorage cleared. Fix: guard null artifactSet.

## MEDIUM

7. **Stance durationExtensions fire after the stance ended** — `notationParser.ts:1894` (onReaction path) + `1780` (onCast path). Both gate only on `stanceWindows.has(charId)`; entries are never deleted (kept for drain settling). Summon path has the correct `endTime > castTime` check at 1910 — mirror it. Repro: Mizuki stance bar uptime 10s instead of 7.5s from an extension firing ~18s after stance death; also poisons downstream `inStance` resolution.
8. **normalCounter not reset by C/D/J/P/E/Q cancels** — `notationParser.ts:2751`. Only reset at segment start (2259) + stance open (2424/2625). `Hu Tao E 9[N1C]` walks the hit table (hit-0 20f → hit-5 no-C-key fallback) instead of using hit-0 each rep — the flagship bracket use case drifts tens of frames. In-game/gcsim: any cancel resets the NA string.
9. **Unspaced `>` separator consumed by `\S+`** — `tokenizer.ts:195`. Typed (not pasted — `normalizePaste` only runs on paste) `Bennett Q>Raiden Q` folds into one unknown token; both segments vanish. Editor theme comment (notationEditorExtension.ts:227) says unspaced separators are expected.
10. **Swap weapon buffs fire between same-character segments** — `RotationTimeline.svelte:1658-1686`. `onSwapIn/onSwapOut` processed for every consecutive track pair without `track.characterId !== nextTrack.characterId`; `connectorStyle`/`trackConnections` (2537/2565) do check. Phantom Widsith proc + falsely consumed 30s procCooldown on `Nahida E N2, Nahida Q`. (2/3 votes — one verifier disputed details, mechanism confirmed.)
11. **computeTeamBuffRows duplicates event-pool bars for multi-segment characters** — `RotationTimeline.svelte:1354` (char onReaction), `1150` (NB), `1265` (artifact onReaction). Rotation-wide event pools iterated inside the per-track loop → same rowKey gets its bars pushed once per track of that character. Kin to the Chevreuse each_key lesson; repro `Bennett E > Kazuha E > Bennett Q > Kazuha Q` doubles Kazuha A4 bars.

## LOW

12. **C-block kind misses catalyst check; plunge ignores infusion** — `notationParser.ts:2785` (C), `2807` (plunge hardcodes 'normal'). `Nahida N2C`: N2 elemental-colored, C physical-colored; `Xiao Q hP` plunge renders physical.
13. **Always-true `cd.width > 0` guard → phantom 2px CD ghost when CD == duration** — `RotationTimeline.svelte:3040` (E row) + `3185` (Q row); `barGeom` clamps width to ≥2 (2524). Single-phase branch guards on un-clamped span correctly (3099/3243). Real data hits it: Mualani E (6s/6s), Nefer E (9s/9s).
14. **Tooltip stuck when hovered bar unmounts** — `RotationTimeline.svelte:3347`. Visibility managed solely by per-bar mouseenter/mouseleave; reactive rebuild (notation edit, zoom) destroys the node, mouseleave never fires, fixed-position tooltip orphaned.

All 9 chars probed end-to-end clean. 3 regression tests.

# The frame pilot — 2026-11-19

Round 3 of the translation item in `docs/todo.md`: the frame extracted, the pseudo-locale,
and a Japanese draft of the frame, all hidden. Three stacked branches:
`feat/i18n-frame`, `feat/i18n-pseudo-locale`, `feat/i18n-ja-frame` (which also carries a
fix to curly apostrophes in two Settings notes), and this record on `docs/i18n-frame-pilot`.

## What was built

- **The frame is extracted.** The top bar, the footer and New tag, the menu state and its
  section table, the landing and its announcements, Settings (the panel, the sound labels,
  the backup errors), and the rest of the error surfaces: 194 messages in
  `messages/en.json`. English is unchanged: the visible text and labels of all 27
  prerendered English pages match `main`'s build line for line (diffed from both builds).
  `/ja` and `/zh` changed only where the landing's dates now follow the locale.
- **No English was reworded.** Every assembled string and hand-made plural the refresh
  record listed for the frame became a whole message with the same English, so there was
  no rewording to propose:
  - one message per case: "Your rotations" and "Your lineups", "Saved · Theorycraft", the
    delete dialog's two closing sentences, the backup summary's parts;
  - plural variants in the message format (`landing_characters_modeled`,
    `settings_saved_since`, the summary's counts);
  - `Intl` in the page's language for "today / yesterday / 3 days ago"
    (`RelativeTimeFormat`), "Main, Alt, and Spare" (`ListFormat`), and the landing's dates;
  - the note order hint, which `orderHint()` spelled from word fragments, is three whole
    messages, with a test in `tones.test.ts` that checks each against `ORDERS`.
- **Bold inside a sentence** is Paraglide markup (`{#strong}Off{/strong}`), rendered by
  `Msg.svelte` through snippets the caller passes, so the element keeps the caller's
  classes. `Emphasis.svelte`'s `**…**` was considered and rejected: Settings' bold values
  carry the stale-backup class, which a marker can't.
- **Module-level tables** read their message at each read: getters in `TOOLS`,
  `SECTION_GROUPS` and `SETTINGS_GROUPS`, and `labels()` (`$lib/i18n/labels.ts`) for the
  sound tables. The unused `tool` field on the menu's section items went.
- **The checks learned variants and markup.** `messages.test.ts` holds every locale to
  English's inputs (placeholders and declared inputs) and markup tags. The extractor reads
  variant messages and counts `m.key.parts(` and `labels({ id: m.key })` as call sites.
  One key was renamed (`menu_help_group`) because a mark name in `MenuState.svelte`
  minted `menu_help`.
- **The pseudo-locale, `en-XA`** (⚓ Nate 2026-11-19). Accented, padded 35%
  (`PSEUDO_GROWTH` in `src/lib/i18n/pseudo.ts`) and bracketed `⟦…⟧`, so a clipped end shows.
  `messages/en-XA.json` is generated by `scripts/generate-pseudo-locale.mjs` and committed,
  because Paraglide's Vite plugin compiles before any step of ours could write it;
  `pseudo.test.ts` fails when it is stale. `noindex` in the head and in `_headers`.
- **A Japanese draft of the frame**, written by Claude for the reviewer, at `/ja`. Game
  terms come from genshin-db's Japanese game text: 深境螺旋, 幽境の激戦, 幻想シアター,
  命ノ星座, 通常攻撃, 元素スキル, 元素爆発, スメール. The house terms are a first
  proposal, listed below.
- **CJK line breaking** is `line-break: strict` (kinsoku) under `:lang(ja)` and
  `:lang(zh-Hans)`: the landing card broke "ローテーションプランナ | ー" on a phone, and now
  breaks "ローテーションプラン | ナー".

## The Japanese house terms (for the reviewer)

The frame's own terms, translated once and reused: ローテーション (rotation), ラインナップ
(lineup), 所持キャラ (Roster), チーム, プランナー, ビルダー, ビジュアライザー,
ローテーションプランナー, チームビルダー, 人の操作タイミング (Human timing), 入力間隔
(Padding), モーション (Animations), カバレッジ帯 (coverage strip), 表記 (notation), ライブラリ,
ゴミ箱 (Trash). Kept in English: critcalc.app, Astrolabe, Ephemeris, Observatory, KQM,
Theorycraft (the guest profile's stored name), and the units f, s and ms.

## Left in English on purpose

The brand, the three card names, units, the scene's shader source, and the stored default
profile names (`My profile`, `Theorycraft` in `backup.ts`). A stored name is data: showing
Theorycraft in Japanese would need a lookup by profile kind, not a message.

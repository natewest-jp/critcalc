## Nate's Stellar trigger model (2026-07-29 — read before touching type shapes or RP wiring)

- **NOT faction-count-conditional** (unlike Secret Rite's `min: 2` hexerei or Ascendant Gleam's 2-moonsign). Stellar buffs are **REACTION-presence-conditional**: a Stellar reaction is ENABLED by specific characters, and when an enabler is in the party, the base reaction is **converted party-wide** (Superconduct → Stellar-Conduct), exactly like Ineffa converting all ElectroCharged → LunarCharged.
- **Currently ONE enabler: Sandrone** (Stellar-Conduct, this patch). 7.0 adds more Conduct enablers + the first Stellar Swirl enablers.
- **Per-reaction gating**: a character whose buffs key off Stellar-Conduct gets NOTHING from a Stellar-Swirl enabler — the specific reaction must be enabled.
- Example: Diona + Electro = Superconduct; add Sandrone → all Superconduct becomes Stellar-Conduct AND Diona's Stellar-Conduct buffs activate.
- **⚠️ SOME buffs are PERMANENT kit patches with no trigger/condition at all** — watch for these while authoring; don't force a reaction gate onto them.
- Schema implication: the buff condition is "team contains an enabler of reaction X" (≈ a `teamEnablesReaction` shape), not `teamFaction`.

# docs

| Folder      | What's in it                                                                                                                                                                                                                                                            |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `design/`   | The current design of a surface or system, kept up to date as it changes.                                                                                                                                                                                               |
| `rounds/`   | One record per round of work: the plan, the rulings, what shipped and why. Dated, and not rewritten afterwards except for marked corrections. `round-history.md` is the digest of rounds from before launch; list the folder (newest records carry dates) for the rest. |
| `curation/` | Character-data curation: generated audit reports, talent sidecars, caveat passes, scope notes.                                                                                                                                                                          |
| `library/`  | Reference material about the game (mechanics, wiki snapshots, in-game logs, gotchas).                                                                                                                                                                                   |
| `text/`     | The user-facing text style guide, glossary and string ledger.                                                                                                                                                                                                           |
| `checkin/`  | State and log for the daily check-in.                                                                                                                                                                                                                                   |
| `archive/`  | Retired briefs and handoffs, kept for history.                                                                                                                                                                                                                          |

The instructions for working in this repo are the root `CLAUDE.md` and `.claude/rules/`.

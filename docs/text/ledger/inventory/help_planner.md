- `help_planner_human_timing_by_default_the_chart_is` — RotationPlanner.svelte:73 <p> — ⚑ off-glossary
  > <strong>Human timing.</strong> By default the chart is frame-perfect: every cancel lands on the first frame the game allows, the way a macro plays. That is what the game permits, but it is not how most rotations go, and a buff that runs out on the chart before it does in your hands is the usual symptom. <em>Human timing</em> in the view bar times the rotation the way a person does. It adds a few frames before every input the game does not buffer — a skill after a normal attack, an aimed shot, the first press after a swap — and can let each animation finish instead of cancelling it. A normal-attack string costs nothing extra, because the game queues the next swing for you. The padding draws as a faint hatch on the active row so you can see where the time went; how many frames, and which of the two adjustments apply, are set in Settings, where KQM's starting point of ten frames is the default. It is your preference, not part of the rotation: a link you share opens frame-perfect for whoever follows it.

  > <strong>Play.</strong> <em>Play</em> in the view bar runs a cursor along the timeline at game speed, with four beats to count you in (the last one higher) and a note at every press. Every start counts in, a resume after a pause included, and the button before Play takes you back to the start — or, while playing, goes again from the top. The notes keep time with the tab hidden, so you can play the rotation with the game in front of you and the chart behind it.
